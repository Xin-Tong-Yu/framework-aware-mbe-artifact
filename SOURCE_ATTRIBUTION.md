# Software and data provenance

This artifact contains adaptations of published MBE implementations.

- MBET and MBETM: **Maximal Biclique Enumeration: A Prefix Tree Based Approach**
  (ICDE 2024). Original authors' algorithm and source attribution must be
  retained when distributing derived code.
- IPS: **Maximal Biclique Enumeration with Improved Worst-Case Time Complexity
  Guarantee: A Partition-Oriented Strategy** (SIGMOD 2026). The pure ET1/ET2
  runner uses an IPS-derived Double framework and related implementation.

The exact licensing and redistribution permissions of upstream code and graph
datasets have **not been established by this package**. Do not infer that an
unlicensed upstream file is available under a permissive license merely because
it is hosted publicly. Confirm and include the original LICENSE and citations
where required before publication.

Cleaned input files are represented by fixed SHA-256 hashes in
`data/COLLECTED_INPUT_SHA256.csv`. Source datasets, links, download dates,
cleaning scripts, and authorizations still need review and documentation.
